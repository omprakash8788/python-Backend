*** How to create project and other setup***

1. Create root level folder
 - Switch in created folder
 - Next flow next step 2
2.  python -m venv .venv
3. Activate venv ` .venv\Scripts\activate     `
 - After that install necessary packages
 4.  pip install fastapi uvicorn

 5. Run app - uvicorn main:app --reload
